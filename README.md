# Jo5-K — G1R Mod Index

## Português

No launcher do G1R, abra **Encontrar mods → Índices → Adicionar** e informe:

`Jo5-K/jo5-k-mod-index`

Alternativa direta: https://raw.githubusercontent.com/Jo5-K/jo5-k-mod-index/main/site/data/index.json

Inclui somente **2D Battle Menu - Jo5-k**, **Glass Menu - Jo5-k** e **Rematch Gen3**. Floating Glass é legado e não faz parte deste catálogo. O índice mostra releases publicadas; alterações que existam somente na instalação local não são distribuídas por ele. Cadastrar o índice não instala nem ativa mods automaticamente em outros dispositivos: escolha instalar e ativar no gerenciador.

O catálogo segue o schema 1 do G1R e contém links para os ZIPs das releases. Atualiza a cada seis horas ou pela execução manual de Refresh mod index. Inclui a pré-release do 2D Battle Menu. Requer G1R 0.3.97+ para os dois mods de interface; Rematch aceita 0.3.93+. Alvos: FireRed, LeafGreen, Ruby, Sapphire e Emerald.

## English

In the G1R launcher, open **Find mods → Indexes → Add** and enter `Jo5-K/jo5-k-mod-index`. The raw JSON URL above also works.

Lists the three independent mods: 2D Battle Menu, Glass Menu and Rematch Gen3. Legacy Floating Glass is excluded. Listings link to published release ZIPs; local-only changes are not distributed. Adding an index does not automatically install or enable mods on other devices.

G1R schema 1; refreshes every six hours and supports manual workflow runs. Includes the battle menu pre-release. Supports all five Generation 3 games. Interface mods require G1R 0.3.97+; Rematch requires 0.3.93+.
