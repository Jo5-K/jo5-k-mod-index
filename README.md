# Jo5-K — G1R Mod Index

## Português

No launcher do G1R, abra **Encontrar mods → Índices → Adicionar** e informe:

`Jo5-K/jo5-k-mod-index`

Alternativa direta: https://raw.githubusercontent.com/Jo5-K/jo5-k-mod-index/main/site/data/index.json

Inclui **2D Battle Menu**, **Glass Menu**, **Rematch Gen3**, **Hoenn PT-BR**, **QoL** e **2.5D Battle Menu**, todos Jo5-k. Floating Glass é legado e não faz parte deste catálogo. Projetos sem release aparecem identificados como em desenvolvimento, sem link de download inventado. Cadastrar o índice não instala nem ativa mods automaticamente: escolha instalar e ativar no gerenciador quando houver uma release disponível.

O catálogo segue o schema 1 do G1R e contém links para os ZIPs das releases. Atualiza a cada seis horas ou pela execução manual de Refresh mod index. Inclui a pré-release do 2D Battle Menu. Requer G1R 0.3.97+ para os dois mods de interface; Rematch aceita 0.3.93+. Alvos: FireRed, LeafGreen, Ruby, Sapphire e Emerald.

## English

In the G1R launcher, open **Find mods → Indexes → Add** and enter `Jo5-K/jo5-k-mod-index`. The raw JSON URL above also works.

Lists six projects: 2D Battle Menu, Glass Menu, Rematch Gen3, Hoenn PT-BR, QoL and 2.5D Battle Menu. Legacy Floating Glass is excluded. Projects without a release remain listed as in development, without a fabricated download. Adding an index does not automatically install or enable mods.

G1R schema 1; refreshes every six hours and supports manual workflow runs. Includes the battle menu pre-release. Supports all five Generation 3 games. Interface mods require G1R 0.3.97+; Rematch requires 0.3.93+.


QoL e 2.5D já possuem betas instaláveis. Para manter 2D e 2.5D carregados juntos, use 2D 1.0.0-rc.4+ e escolha apenas uma apresentação em SELECT → Ajustes → Modo de batalha. Hoenn PT-BR continua listado sem release própria.
